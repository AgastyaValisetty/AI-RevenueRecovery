The Revenue Recovery Simulation project has three key documentation files that are **git-ignored**:

- `Architecture.md` — Original high-level architecture spec (1812 lines)
- `architecture2.md` — Deep-dive micro-specification (2007 lines) covering every class, function, API endpoint, DB table, and FK relationship
- `UML_Design.md` — PlantUML diagrams (656 lines) including aggregate class diagram, per-service class diagrams, ER diagram, sequence diagrams, state diagrams, and activity diagram

The `.gitignore` file already ignores all three markdown files.
